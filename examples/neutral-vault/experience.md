# Experiences and short-term context

Generated from the event journal. Two different things live here:

- **Experiences** are reusable, evidence-backed findings: a verified path, a ruled-out search
  route, a corrected failure, a workflow that worked. They are advisory — never a user

  revalidated before reuse.

  expires, then dormant and history-only. Dormancy is not deletion.
